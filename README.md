# Pulsus

**Find your rhythm.** A calm personal system for capturing ideas, managing projects, and protecting balance.

Pulsus is a cross-platform mobile app for iOS and Android, built with Expo, React Native and TypeScript.

## MVP goals
- Capture ideas quickly, without forcing an immediate commitment.
- Turn selected ideas into projects with time and money budgets.
- Track time spent on projects.
- Make personal balance visible without gamification or guilt.
- Review, pause, resume or complete projects intentionally.

## Stack
- Expo SDK 54 + React Native
- TypeScript
- Expo Router
- AsyncStorage for local-first persistence

## Run locally

    npm install
    npx expo start

Scan the QR code with Expo Go, or use an iOS Simulator / Android Emulator.

## Product principles
1. Encourage awareness, never shame.
2. Protect creativity; don't suppress enthusiasm.
3. Pausing is a valid decision, not a failure.
4. Start simple and keep cognitive load low.
5. Pulsus is a planning and self-management tool, not a medical or diagnostic product.

## Status
Early MVP foundation. Data is stored locally on the device; cloud sync and accounts are intentionally out of scope for this first iteration.
